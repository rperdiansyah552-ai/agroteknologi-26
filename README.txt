# WEBSITE AGROTEKNOLOGI 26

Website album foto sederhana untuk Agroteknologi Angkatan 2026 UIN Sultan Syarif Kasim Riau.

## Cara menjalankan
1. Extract ZIP ini.
2. Buka folder `website_agroteknologi_26`.
3. Klik dua kali `index.html`.
4. Website akan langsung terbuka di browser.

## Cara mengganti foto
Semua foto ada di folder `images`.
Jika ingin mengganti foto, gunakan nama file yang sama agar HTML tidak perlu diubah.

## Cara mengganti teks
Buka `index.html` menggunakan VS Code, Notepad++, atau editor teks lainnya.

## Catatan
Website sudah responsif untuk laptop dan HP.
Foto pada galeri bisa diklik untuk membuka tampilan besar.


## Musik
Musik background sudah disertakan sebagai `music.m4a`.
Tekan tombol MUSIK di pojok kanan bawah untuk memutar atau menghentikannya.
